# 设计规范

## 色彩体系

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主题色 | `#009688` (teal) | 侧边栏、按钮、高亮元素 |
| 主题色浅 | `#26a69a` | hover 状态 |
| 主题色深 | `#00796b` | 按钮按下状态 |
| 背景色 | `#f5f5f5` | 页面背景 |
| 卡片背景 | `#ffffff` | 内容卡片 |
| 正文色 | `#333333` | 内容文字、标题 |
| 辅助色 | `#999999` | 朝代·作者等次要信息 |
| 搜索结果高亮 | `#e8f5e9` | 搜索结果 hover 背景 |

## 字体

| 用途 | 字体 | 备选 |
|------|------|------|
| 诗文/经文内容 | "Noto Serif SC", "思源宋体", serif | 系统衬线字体 |
| 界面文字 | -apple-system, "Microsoft YaHei", sans-serif | 系统无衬线字体 |

## 布局

### 桌面端（> 600px）

- 侧边栏固定左侧，宽度 180px，背景主题色
- 内容区：max-width 600px，居中
- 卡片圆角：12px
- 卡片阴影：`0 2px 12px rgba(0,0,0,0.08)`
- 内边距：卡片内 32px

### 移动端（≤ 600px）

- 侧边栏变为顶部横向可滚动 Tab 栏
- 内容区撑满屏幕宽度，左右边距 16px
- PWA 安全区适配（safe-area-inset）

## 组件样式

### 侧边栏（桌面）
- 背景：主题色 `#009688`
- 文字：白色，15px
- 当前选中：半透明白色背景
- 项目高度：48px

### Tab 栏（移动）
- 背景：主题色 `#009688`
- 横向滚动，不换行
- 当前选中：底部白色指示条

### 内容卡片
- 背景：白色，圆角 12px
- 标题：24px，加粗，居中
- 元信息（朝代·作者）：14px，灰色，居中
- 诗文/经文：20px，衬线字体，居中，行高 2
- 故事内容：16px，无衬线字体，左对齐

### 周易卦象符号
- 字号：48px，居中

### 搜索栏
- 输入框 + 搜索按钮横向排列
- 输入框圆角，高度 40px
- 搜索按钮胶囊形，主题色背景

### 搜索结果列表
- 每条结果：左对齐，标题 + 来源信息
- hover：浅绿色背景
- 分隔线

### 操作按钮
- 高度：44px
- 圆角：22px（胶囊形）
- 背景：主题色，白色文字
- hover：主题色浅

### Toast 提示
- 位置：页面底部居中
- 背景：半透明黑色
- 文字：白色，14px
- 自动消失：2 秒后淡出

## 动效

- 内容切换：淡入淡出，300ms ease
- 按钮点击：缩放 0.95，150ms
- Toast：底部滑入，200ms ease-out
