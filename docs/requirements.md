# 开发需求文档

## 项目概述

国学经典随机展示网站 —— 一个轻量级 PWA 应用，支持周易、老子、庄子、论语、唐诗、宋词、成语故事、寓言故事八种内容的随机浏览和搜索。可添加到手机主屏幕离线使用。

## 功能需求

### 核心功能

| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| F1 | 多类型导航 | P0 | 侧边栏切换八种内容类型 |
| F2 | 随机展示 | P0 | 每种类型独立随机展示一条内容 |
| F3 | 换一首 | P0 | 点击按钮随机切换，避免连续重复 |
| F4 | 关键词搜索 | P1 | 在当前类型内按关键词搜索（点击触发） |
| F5 | 分享内容 | P1 | 将当前内容文本复制到剪贴板 |
| F6 | PWA 支持 | P1 | 可添加到手机主屏幕，支持离线使用 |

### 内容类型与展示字段

| 类型 | 标识 | 展示字段 |
|------|------|---------|
| 周易 | yijing | 卦名、卦象符号、卦辞、象辞、彖传、六爻爻辞 |
| 老子 | laozi | 章号、章名、经文段落 |
| 庄子 | zhuangzi | 篇名、经文段落 |
| 论语 | lunyu | 篇名、标题、语录段落 |
| 唐诗 | poem | 标题、朝代·作者、诗文段落 |
| 宋词 | ci | 标题、朝代·作者、词文段落 |
| 成语故事 | idiom | 标题、释义、故事 |
| 寓言故事 | fable | 标题、故事、寓意 |

### 非功能需求

- 纯前端实现，无需服务器
- Preact + HTM 组件化架构，ES Modules
- 无构建工具，浏览器直接打开即可运行
- 响应式设计：桌面端侧边栏 + 内容区，移动端顶部 Tab 栏
- 青绿色主题色
- PWA 离线缓存（Service Worker）

## 用户故事

1. **作为用户**，我可以通过侧边栏切换不同的国学内容类型。
2. **作为用户**，我希望打开网页就能看到随机内容，以便随时品味经典。
3. **作为用户**，我希望点击「换一首」随机看到不同的内容。
4. **作为用户**，我可以搜索关键词找到感兴趣的内容。
5. **作为用户**，我可以把内容文本复制分享给朋友。
6. **作为用户**，我可以把网站添加到手机主屏幕，离线也能使用。

## 验收标准

- [ ] 页面加载后显示侧边栏和随机内容
- [ ] 点击侧边栏各类型，内容正确切换
- [ ] 每种类型「换一首」功能正常，不连续重复
- [ ] 输入关键词搜索，结果列表正确显示
- [ ] 点击搜索结果，显示完整内容卡片
- [ ] 点击「分享」，剪贴板包含格式化文本
- [ ] 手机浏览器中布局正常（顶部 Tab + 卡片撑满）
- [ ] PWA 可添加到主屏幕，离线可用
